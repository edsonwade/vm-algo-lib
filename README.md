## 🧰 Data Structures & Algorithms Library 📚

Welcome to my Data Structures & Algorithms library! This repository is designed to provide a collection of
essential data structures and algorithms that I implement and use across my personal projects.
The goal is to have a ready-to-use set of well-implemented structures and algorithms that can be easily incorporated
into various projects.

📁 Project Structure

**algorithms**: A collection of algorithms categorized by technique (e.g., searching, sorting, dynamic programming,
recursion).

**datastructures**: Implementations of common data structures (e.g., stacks, queues, linked lists, trees, graphs, sets,
lists, maps).

**utils**: Helper functions for mathematics, string manipulations, arrays, and graph utilities.

## Some insights

1. **Arrays**:
   Simple yet efficient way to store data in a contiguous memory location.

2. **Linked List**:
   A linear data structure with nodes that hold data and references to the next node.

3. **Stack**:
   LIFO (Last In, First Out) structure, perfect for managing recursion, undo operations, and parsing expressions.

4. **Queue**:
   FIFO (First In, First Out) structure, ideal for scheduling tasks, handling resources, or message queues.

5. **Hash Map**:
   A key-value store that allows for constant-time average lookups and insertions.

6. **Trees**:
   Binary Search Tree (BST): Organize data for efficient search, insertion, and deletion.
   AVL Tree: A self-balancing binary search tree.

7. **Heaps**:
   A specialized tree-based data structure used for efficient priority queues (min-heap and max-heap).

8. **Graphs**:
   Represent connections or relationships between items.
   Includes Adjacency List and Adjacency Matrix representations.

9. **Disjoint Set (Union-Find)**:
   A powerful data structure to manage a partition of a set into disjoint subsets.
   Includes path compression and union by rank for efficiency
